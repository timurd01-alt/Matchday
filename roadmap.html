Current limits

What the site doesn't do yet

Matchday Terminal is one person's project, built on free data sources. That keeps it independent, but some things you'd expect from a scores site aren't here yet. Here's why.

Updated hourly, not live

Scores, ratings and picks refresh once an hour. A game in progress won't update in real time, and a final score can take up to an hour to appear.

Final scores, not box scores or play-by-play

The site's sources reliably supply schedules and final scores. Detailed game stats either aren't available from them for free or can't be shown here under their terms, so the site shows only what it is allowed to show.

Data budgets can run out

Free data sources limit how many requests the site can make each month. The site rations that budget, but if one runs out, that sport holds at its last published numbers until the budget resets rather than guessing.

No in-game predictions

Picks lock an hour before kickoff and are graded once the game is final. Win chances don't update during a game.

Basketball ratings use results only

Men's college basketball ratings come from results and scoring margins. Pace- and efficiency-adjusted ratings need per-game team stats the site doesn't have a source for yet.

Two sports

The site covers college football and men's college basketball only, so it can do those two properly.

What's next

Planned, and what's in the way

These are goals, not promises, so there are no dates. Each one says what it's waiting on.

Box scoresWaiting on a data source that supplies team stats and allows them to be shown.
Efficiency-based basketball ratingsNeeds the same team-stats source as box scores.
Live scoresNeeds a real-time feed; the site currently refreshes once an hour.
Play-by-playNeeds a play-by-play source that can be shown, plus live updates.
In-game win probabilityNeeds live scores first, then an in-game model tested before it's published.

Shipped changes are listed in the release notes on the site's Updates page.
